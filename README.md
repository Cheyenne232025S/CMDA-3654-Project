# CMDA-3654-Project (Intro Data Analytics and Visual)

This project was done in collaboration with Cheyenne Erickson, Kathleen Reece, Ziad Bushnaq, Evan Merricks, and Hannah Young. 

The two main objetives of this project was to indetify the main SAT score predictors in 2014/2015 and gain understanding of their affects. Next, we wanted to visualize how similair states are based on their educational and SAT performace data, and compare these clusters to how the US Census Bureau divides the states into geographic regions. 

To view the entire complete project download data from data folder then open and run the notebook named project 2. 
This project was an iterative process.
